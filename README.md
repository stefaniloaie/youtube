# YouTube History Summarizer (Chrome Extension + FastAPI Backend)

Pre-configured to connect to your live Railway cloud service:
https://youtube-production-9f45.up.railway.app

## Features Included:
- Manifest V3 with options_ui and chrome.storage.sync for BYOK (Google AI Studio Key)
- Automatic fallback to shared gemini-2.5-flash model
- Live Railway backend integration

## Quick Installation into Chrome:
1. Extract this .zip folder onto your computer.
2. Open Google Chrome and go to chrome://extensions
3. Enable "Developer mode" (toggle in the top-right corner).
4. Click "Load unpacked".
5. Select the extracted folder (the folder containing manifest.json directly).
6. Click the extension icon in your Chrome toolbar to view today's YouTube history and summarize!
